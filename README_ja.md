# iDrive Maps（Tasker「Maps-V4」の置き換えアプリ）

BMW iDrive のコントローラー操作を Android ヘッドユニット（KSW 系）のログ `KswMcuListener` から検出し、
**Googleマップ表示中だけ** 地図を操作する常駐アプリです。Tasker + AutoInput/TouchTask で行っていた処理を1本にまとめています。

| iDrive 操作 | ログ (cmdType:A1) | Googleマップでの動作 |
|---|---|---|
| 上に倒す | data:17-01-01 | 上スワイプ (500,200→500,300) |
| 下に倒す | data:17-02-01 | 下スワイプ (500,200→500,100) |
| 右に倒す | data:17-03-01 | 右スワイプ (500,200→600,200) |
| 左に倒す | data:17-04-01 | 左スワイプ (500,200→400,200) |
| 押し込み | data:17-05-01 | 「開始/Start」「通勤」「現在地に戻る」等のボタンをタップ |
| 左に回す | data:17-06-01 | ズームアウト（2本指タップ×2） |
| 右に回す | data:17-07-01 | ズームイン（600,240 ダブルタップ） |

座標は Tasker と同じ 1280×480 基準で、実際の画面サイズに合わせて自動で拡大縮小します（設定でOFF可）。

## 1. APK を作る（どちらか）

**A. GitHub で自動ビルド（PC に開発環境不要）**
1. GitHub に新しいリポジトリを作り、このフォルダの中身をすべてアップロード
2. 「Actions」タブ → 「Build APK」が自動で実行される（数分）
3. 完了した実行を開き、Artifacts の `IDriveMaps-apk` をダウンロード → 中の `app-debug.apk`

**B. Android Studio**
フォルダを「Open」→ ▶ Run（または Build > Build APK）。

## 2. ヘッドユニットに入れて設定

1. APK をUSBメモリ等でインストール（提供元不明アプリを許可）
2. **ログ読み取り権限を付与**（Tasker でも同じことをしていたはずです）。PC から:
   ```
   adb shell pm grant com.idrive.mapscontrol android.permission.READ_LOGS
   ```
   root 化済みなら、アプリ内の「root化済みならここで権限付与」ボタンでも可。
3. アプリ内の「① ユーザー補助の設定を開く」→「iDrive Maps コントロール」を ON
4. アプリの状態欄が「✅ 動作中 / ✅ あり / 監視中」になれば完了。以後、起動時も自動で常駐します。

> Android 13 以降は、ログ読み取り時に「すべてのデバイスログへのアクセスを許可しますか？」と出ることがあります。「許可」を選んでください。

## 3. 動かないとき

- **「デバッグログを表示」をON** → iDrive を操作。アプリのログ欄に `LOG ... cmdType:A1 - data:17-0x-01` が出ていれば受信OK。
  何も出ない場合は READ_LOGS 権限かログタグ（初期値 `KswMcuListener`）を確認。
- **押し込みで何も押されない**：ログ欄に「画面上のボタン: 「…」」と、そのとき押せる文字が出ます。
  押したい文字を「押し込み時にタップするボタンの文字」に1行で追加して保存してください。
- **スワイプ位置がずれる**：「座標を画面サイズに合わせて自動調整」をON/OFFして試してください。
- **テストボタン**：押してから5秒以内にGoogleマップへ切り替えると、その動作が実行されます。
- 機種によっては省電力設定でユーザー補助が切られることがあります。その場合はアプリの電池最適化を「制限なし」にしてください。
